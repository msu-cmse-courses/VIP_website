# VIP Course Website

This repository contains the course website for the
Vertically Integrated Projects (VIP) Program at Michigan State University.

## Purpose
- Share course information
- Highlight projects and team members
- Publish updates and resources

## Built With
- Jekyll
- al-folio theme (customized)

## Live Site
https://msu-cmse-courses.github.io/VIP_website/
